# Resume Builder App using Flutter

## Project Description

The Resume Builder App is a mobile application developed with Flutter that enables users to create and customize professional resumes easily. This project serves as an educational tool to showcase essential Flutter concepts, including state management, user input handling, and dynamic UI generation. The app features a sleek and intuitive interface, allowing users to focus on creating an impactful resume.

### Flutter Packages Used

The app utilizes various Flutter packages to enhance functionality and user experience, including:

- **flutter_form_builder**: For managing forms and validations effectively.
- **provider**: For state management, ensuring a reactive UI.

## Project Objectives

### User-Friendly Interface

The app is designed with a clean and modern UI that simplifies the resume creation process, making it accessible to users of all skill levels.

### Customizable Resumes

- **Template Selection**: Users can choose from multiple resume templates to suit their personal branding.
- **Real-Time Preview**: Changes are reflected instantly in the resume preview, allowing users to see their updates in real-time.

## Project Technologies

- **Language**: Dart
- **Dependencies**: flutter_form_builder, provider
- **Development Tools**: Android Studio, VS Code, IntelliJ IDEA

## App Features

- **User Authentication**: Users can create accounts to save and manage their resumes.
- **Template Options**: A variety of resume templates for users to choose from.
- **Form Fields**: Customizable sections for personal information, work experience, education, and skills.
- **Real-Time Editing**: Changes made to the resume are instantly updated in the preview.
- **Export Options**: Users can export their resumes in PDF format for easy sharing.
- **Save & Load Resumes**: Functionality to save drafts and load previously created resumes.
